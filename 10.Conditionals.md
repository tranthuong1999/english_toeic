If you do not study, you will fail.

10.8 Mixed Conditionals
Mixed Conditional = điều kiện và kết quả nằm ở hai mốc thời gian khác nhau.
If + had + V3, would + V
→ nguyên nhân quá khứ → kết quả hiện tại

* If she had studied computer science, she ___ a software developer now.

A. will be
B. would be (
C. would have been
D. is

Third Conditional:

If she had studied, she would have become a developer.
→ quá khứ → quá khứ

If she had studied, she would be a developer now.
→ quá khứ → hiện tại

* If the software ___ properly, users will not experience any problems.
A. installed
B. installs
C. is installed
D. would install

❌ Chưa đúng. Đáp án: C. is installed

If the software is installed properly, users will not experience any problems.

Vì sao?

Đây là First Conditional:

If + Present Simple → will + V

Nhưng cần chú ý: software không tự cài đặt → nó được cài đặt.

Vì vậy cần bị động:

is + V3 → is installed

is installed ✅ Present Simple Passive
will not experience ✅ kết quả tương lai
So sánh

❌ If the software installed properly...
→ thiếu trợ động từ be.

❌ If the software installs properly...
→ mang nghĩa software tự thực hiện hành động cài đặt, không phù hợp ý câu.

✅ If the software is installed properly...

* If the team had checked the server, the problem ___ before the system crashed.

A. would detect
B. would have been detected (
C. will be detected
D. is detected
Vì sao?

Đây là Third Conditional + Passive Voice.

Công thức Third Conditional:

If + had + V3 → would have + V3

Nhưng the problem không tự phát hiện → nó được phát hiện → cần bị động.

would have been + V3

→ would have been detected ✅

Tách câu ra:
had checked → Past Perfect
would have been detected → Conditional Perfect Passive
before the system crashed → sự việc đều nằm trong quá khứ

❌ A. would detect
→ thiếu have been, sai cả thời gian lẫn thể bị động.
