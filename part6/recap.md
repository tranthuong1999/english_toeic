├── 1. WORD FORM — TỪ LOẠI
│   │
│   ├── 1.1. Noun — Danh từ
│   │   ├── Danh từ số ít / số nhiều
│   │   ├── Đếm được / không đếm được
│   │   ├── Hậu tố: -tion, -ment, -ness, -ity
│   │   └── a/the + N; adjective + N
│   │       VD: The company made a decision.
│   │       → Công ty đã đưa ra một quyết định.
│   │
│   ├── 1.2. Verb — Động từ
│   │   ├── Động từ chính / trợ động từ
│   │   ├── Chia theo chủ ngữ
│   │   ├── V / V-ing / V3
│   │   └── Hậu tố: -ize, -ify, -en
│   │       VD: The company provides training.
│   │       → Công ty cung cấp chương trình đào tạo.
│   │
│   ├── 1.3. Adjective — Tính từ
│   │   ├── Đứng trước danh từ
│   │   ├── Đứng sau linking verbs
│   │   └── Hậu tố: -ive, -al, -able, -ous
│   │       VD: The new system is effective.
│   │       → Hệ thống mới có hiệu quả.
│   │
│   ├── 1.4. Adverb — Trạng từ
│   │   ├── Bổ nghĩa cho động từ
│   │   ├── Bổ nghĩa cho tính từ
│   │   └── Bổ nghĩa cho cả câu
│   │       VD: Employees worked efficiently.
│   │       → Nhân viên làm việc hiệu quả.
│   │
│   ├── 1.5. Word Families — Họ từ
│   │   ├── success / succeed / successful / successfully
│   │   ├── decide / decision / decisive
│   │   ├── apply / application / applicant
│   │   └── produce / product / production
│   │       VD: Her application was accepted.
│   │       → Đơn đăng ký của cô ấy được chấp nhận.
│   │
│   └── 1.6. Bẫy từ loại
│       ├── Từ cùng gốc khác nghĩa
│       ├── -ed / -ing
│       ├── Từ chỉ người / chỉ sự việc
│       └── Đúng từ loại nhưng sai nghĩa
│           VD: technical assistance = hỗ trợ kỹ thuật
│               technical assistant = trợ lý kỹ thuật

├── 2. GRAMMAR IN CONTEXT — NGỮ PHÁP
│   │
│   ├── 2.1. Sentence Structure — Cấu trúc câu
│   │   ├── S + V
│   │   ├── S + V + O
│   │   ├── S + be + Complement
│   │   └── Mệnh đề độc lập / phụ thuộc
│   │       VD: The manager approved the request.
│   │       → Quản lý đã phê duyệt yêu cầu.
│   │
│   ├── 2.2. Subject–Verb Agreement
│   │   ├── Chủ ngữ số ít / số nhiều
│   │   ├── Each / every + N số ít
│   │   ├── Either...or / neither...nor
│   │   └── Cụm giới từ chen giữa S và V
│   │       VD: Each employee receives an ID.
│   │       → Mỗi nhân viên nhận một mã ID.
│   │
│   ├── 2.3. Tenses — Các thì
│   │   ├── Present Simple / Continuous / Perfect
│   │   ├── Past Simple / Continuous / Perfect
│   │   └── Future forms
│   │       VD: The company has expanded since 2022.
│   │       → Công ty đã mở rộng kể từ năm 2022.
│   │
│   ├── 2.4. Active / Passive — Chủ động / Bị động
│   │   ├── S + V + O
│   │   ├── S + be + V3
│   │   ├── Modal + be + V3
│   │   └── have/has been + V3
│   │       VD: The report was submitted yesterday.
│   │       → Báo cáo đã được nộp hôm qua.
│   │
│   ├── 2.5. Gerund / Infinitive
│   │   ├── V + V-ing
│   │   ├── V + to V
│   │   ├── Preposition + V-ing
│   │   └── allow / encourage + O + to V
│   │       VD: She avoids making mistakes.
│   │       → Cô ấy tránh mắc lỗi.
│   │
│   ├── 2.6. Modal Verbs
│   │   ├── can / could
│   │   ├── may / might
│   │   ├── must / have to
│   │   └── should + V
│   │       VD: Employees must wear badges.
│   │       → Nhân viên phải đeo thẻ.
│   │
│   ├── 2.7. Relative Clauses
│   │   ├── who / whom / whose
│   │   ├── which / that
│   │   ├── where / when
│   │   └── Rút gọn mệnh đề quan hệ
│   │       VD: The person who called is our client.
│   │       → Người đã gọi là khách hàng của chúng tôi.
│   │
│   ├── 2.8. Conditionals — Câu điều kiện
│   │   ├── Zero Conditional
│   │   ├── First Conditional
│   │   ├── Second Conditional
│   │   └── unless / provided that
│   │       VD: If you need help, contact HR.
│   │       → Nếu cần giúp đỡ, hãy liên hệ HR.
│   │
│   ├── 2.9. Comparison — So sánh
│   │   ├── Comparative: -er / more
│   │   ├── Superlative: -est / most
│   │   ├── as...as
│   │   └── less...than
│   │       VD: This method is more efficient.
│   │       → Phương pháp này hiệu quả hơn.
│   │
│   ├── 2.10. Conjunctions / Prepositions
│   │   ├── because + S + V
│   │   ├── because of + N / V-ing
│   │   ├── although + S + V
│   │   └── despite + N / V-ing
│   │       VD: Despite the delay, the event continued.
│   │       → Dù bị trì hoãn, sự kiện vẫn tiếp tục.
│   │
│   └── 2.11. Bẫy ngữ pháp
│       ├── Đúng ngữ pháp nhưng sai ngữ cảnh
│       ├── Nhầm động từ chính / trợ động từ
│       ├── Nhầm V-ing / danh từ
│       └── Nhầm V3 / tính từ
│           VD: The door is closed.
│               → Cửa đang ở trạng thái đóng.

├── 3. CONNECTORS / TRANSITION WORDS — TỪ NỐI
│   │
│   ├── 3.1. Nhận diện quan hệ giữa các ý
│   │   ├── Nguyên nhân → kết quả
│   │   ├── Đối lập / tương phản
│   │   ├── Bổ sung
│   │   ├── Ví dụ / giải thích
│   │   └── Trình tự / thời gian
│   │       VD: It rained. Therefore, the event was delayed.
│   │       → Trời mưa. Vì vậy, sự kiện bị hoãn.
│   │
│   ├── 3.2. Cause & Effect — Nguyên nhân / Kết quả
│   │   ├── because
│   │   ├── because of
│   │   ├── therefore
│   │   ├── as a result
│   │   └── consequently
│   │       VD: Because of the rain, the event was delayed.
│   │       → Vì trời mưa, sự kiện bị hoãn.
│   │
│   ├── 3.3. Contrast — Đối lập
│   │   ├── although / even though
│   │   ├── despite / in spite of
│   │   ├── however
│   │   ├── nevertheless
│   │   └── whereas / while
│   │       VD: However, the project was completed on time.
│   │       → Tuy nhiên, dự án vẫn hoàn thành đúng hạn.
│   │
│   ├── 3.4. Addition — Bổ sung
│   │   ├── also
│   │   ├── in addition
│   │   ├── additionally
│   │   ├── furthermore
│   │   └── moreover
│   │       VD: In addition, free parking is available.
│   │       → Ngoài ra, có chỗ đỗ xe miễn phí.
│   │
│   ├── 3.5. Example / Explanation
│   │   ├── for example
│   │   ├── for instance
│   │   ├── such as
│   │   └── specifically
│   │       VD: Office supplies, such as paper, are available.
│   │       → Đồ dùng văn phòng như giấy luôn có sẵn.
│   │
│   ├── 3.6. Sequence / Time
│   │   ├── first / next / then
│   │   ├── afterward / subsequently
│   │   ├── meanwhile
│   │   └── finally
│   │       VD: First, complete the form. Then, sign it.
│   │       → Đầu tiên điền biểu mẫu, sau đó ký tên.
│   │
│   ├── 3.7. Purpose / Condition
│   │   ├── so that
│   │   ├── in order to
│   │   ├── so as to
│   │   ├── if / unless
│   │   └── provided that
│   │       VD: We left early so that we could arrive on time.
│   │       → Chúng tôi đi sớm để có thể đến đúng giờ.
│   │
│   └── 3.8. Phân biệt cấu trúc
│       ├── because + S + V
│       ├── because of + N / V-ing
│       ├── although + S + V
│       ├── despite + N / V-ing
│       └── such as + N / cụm danh từ
│           VD: Although it rained, we continued.
│           → Mặc dù trời mưa, chúng tôi vẫn tiếp tục.
│
├── 4. PRONOUN / REFERENCE — ĐẠI TỪ THAM CHIẾU
│   │
│   ├── 4.1. Subject Pronouns
│   │   ├── I / you / he / she / it
│   │   └── we / they
│   │       VD: The computers are new. They work well.
│   │       → Máy tính mới. Chúng hoạt động tốt.
│   │
│   ├── 4.2. Object Pronouns
│   │   ├── me / you / him / her
│   │   └── it / us / them
│   │       VD: Please send them to the manager.
│   │       → Vui lòng gửi chúng cho quản lý.
│   │
│   ├── 4.3. Possessives — Sở hữu
│   │   ├── my / your / his / her / its
│   │   ├── our / their
│   │   └── mine / yours / theirs
│   │       VD: Employees must bring their IDs.
│   │       → Nhân viên phải mang theo thẻ ID.
│   │
│   ├── 4.4. Demonstratives — Chỉ định
│   │   ├── this / that
│   │   └── these / those
│   │       VD: This will improve the process.
│   │       → Điều này sẽ cải thiện quy trình.
│   │
│   ├── 4.5. Xác định đối tượng tham chiếu
│   │   ├── Tìm danh từ được thay thế
│   │   ├── Kiểm tra số ít / số nhiều
│   │   ├── Kiểm tra chủ ngữ / tân ngữ
│   │   └── Xem xét ý của câu trước
│   │       VD: The laptops are ready. They are on the desk.
│   │       → Máy tính đã sẵn sàng. Chúng ở trên bàn.
│   │
│   └── 4.6. Bẫy tham chiếu
│       ├── Danh từ gần nhất chưa chắc đúng
│       ├── it / they / them
│       ├── its / their
│       └── this có thể thay cho cả sự việc
│           VD: Sales increased. This pleased the manager.
│           → Doanh số tăng. Điều này khiến quản lý hài lòng.

├── 7. SENTENCE LOGIC — LOGIC GIỮA CÁC CÂU
│   │
│   ├── 7.1. Cause → Effect
│   │   └── VD: Demand increased, so sales rose.
│   │       → Nhu cầu tăng nên doanh số tăng.
│   │
│   ├── 7.2. Problem → Solution
│   │   └── VD: The system failed, so IT repaired it.
│   │       → Hệ thống lỗi nên IT sửa nó.
│   │
│   ├── 7.3. Action → Purpose
│   │   └── VD: We trained staff to improve service.
│   │       → Chúng tôi đào tạo nhân viên để cải thiện dịch vụ.
│   │
│   ├── 7.4. Statement → Explanation
│   │   └── VD: Sales improved. For example, online orders doubled.
│   │       → Doanh số cải thiện; chẳng hạn, đơn online tăng gấp đôi.
│   │
│   ├── 7.5. Contrast / Concession
│   │   └── VD: Although it was expensive, we bought it.
│   │       → Dù đắt, chúng tôi vẫn mua.
│   │
│   ├── 7.6. Sequence
│   │   └── VD: First, log in. Next, upload the file.
│   │       → Đầu tiên đăng nhập, tiếp theo tải tệp lên.
│   │
│   └── 7.7. Logic toàn đoạn
│       ├── Mở đầu → chi tiết → kết luận
│       ├── Thông báo → hành động cần làm
│       ├── Vấn đề → giải pháp → kết quả
│       └── VD: A deadline is announced, then instructions follow.
│           → Nêu hạn chót rồi đưa ra hướng dẫn.

├── 8. TENSE & TIME CONTEXT — THÌ VÀ THỜI GIAN
│   │
│   ├── 8.1. Time Signals
│   │   ├── yesterday / last / ago
│   │   ├── now / currently
│   │   ├── since / for
│   │   ├── already / yet / recently
│   │   └── tomorrow / next
│   │       VD: The office opened last year.
│   │       → Văn phòng mở cửa năm ngoái.
│   │
│   ├── 8.2. Past Context
│   │   ├── Past Simple
│   │   ├── Past Continuous
│   │   └── Past Perfect
│   │       VD: The meeting had ended before I arrived.
│   │       → Cuộc họp đã kết thúc trước khi tôi đến.
│   │
│   ├── 8.3. Present Context
│   │   ├── Present Simple
│   │   ├── Present Continuous
│   │   └── Present Perfect
│   │       VD: She has worked here for five years.
│   │       → Cô ấy đã làm ở đây được năm năm.
│   │
│   ├── 8.4. Future Context
│   │   ├── will + V
│   │   ├── be going to + V
│   │   ├── Present Continuous cho kế hoạch đã sắp xếp
│   │   └── Present Simple cho lịch cố định
│   │       VD: The training will begin tomorrow.
│   │       → Buổi đào tạo sẽ bắt đầu ngày mai.
│   │
│   ├── 8.5. Tense Relationship
│   │   ├── Hành động trước sự kiện quá khứ
│   │   ├── Hành động hoàn thành trong quá khứ
│   │   ├── Quá khứ kéo dài đến hiện tại
│   │   └── Hiện tại dẫn đến tương lai
│   │       VD: After she received the email, she replied.
│   │       → Sau khi nhận email, cô ấy trả lời.
│   │
│   └── 8.6. Timeline & Bẫy thì
│       ├── Xác định mốc thời gian
│       ├── Xác định hành động trước / sau
│       └── Kiểm tra toàn đoạn
│           VD: Since 2023, sales have increased.
│           → Từ năm 2023 đến nay, doanh số đã tăng.

├── 9. SENTENCE INSERTION — CHÈN CÂU
│   │
│   ├── 9.1. Chức năng câu
│   │   ├── Giới thiệu
│   │   ├── Giải thích
│   │   ├── Ví dụ
│   │   ├── Kết quả
│   │   └── Kết luận
│   │       VD: "For example, ..." cần ý khái quát đứng trước.
│   │
│   ├── 9.2. Câu trước
│   │   ├── Chủ đề
│   │   ├── Danh từ được nhắc lại
│   │   └── Quan hệ logic
│   │       VD: The system is new. This system...
│   │
│   ├── 9.3. Câu sau
│   │   ├── Đại từ có đối tượng tham chiếu không?
│   │   ├── Ý có được giải thích không?
│   │   └── Mạch văn có liên tục không?
│   │       VD: The system launched. It is now available.
│   │
│   ├── 9.4. Reference Words
│   │   ├── it / they / these / those
│   │   ├── this / that
│   │   └── such + noun
│   │       VD: The policy changed. This surprised staff.
│   │       → Chính sách thay đổi. Điều này khiến nhân viên bất ngờ.
│   │
│   ├── 9.5. Connectors & Flow
│   │   ├── However → tương phản
│   │   ├── Therefore → kết quả
│   │   ├── For example → ví dụ
│   │   └── In addition → bổ sung
│   │       VD: The service is free. In addition, it is fast.
│   │
│   └── 9.6. Bẫy chèn câu
│       ├── Chỉ hợp câu trước
│       ├── Chỉ hợp câu sau
│       ├── Sai đối tượng tham chiếu
│       └── Sai trình tự thông tin
│           VD: Câu kết luận không nên đứng trước phần giải thích.

├── 10. DOCUMENT STRUCTURE — CẤU TRÚC VĂN BẢN
│   │
│   ├── 10.1. Email
│   │   ├── Subject / Greeting
│   │   ├── Opening / Purpose
│   │   ├── Main Information
│   │   ├── Request / Action
│   │   └── Closing / Signature
│   │       VD: Please submit the form by Friday.
│   │       → Vui lòng nộp biểu mẫu trước thứ Sáu.
│   │
│   ├── 10.2. Notice / Announcement
│   │   ├── Sự kiện hoặc thay đổi
│   │   ├── Đối tượng áp dụng
│   │   ├── Ngày hiệu lực
│   │   ├── Hạn chót
│   │   └── Hành động cần thực hiện
│   │       VD: The new policy takes effect on May 1.
│   │       → Chính sách mới có hiệu lực ngày 1/5.
│   │
│   ├── 10.3. Invitation / Event
│   │   ├── Sự kiện
│   │   ├── Thời gian / địa điểm
│   │   ├── Người tham dự
│   │   └── RSVP
│   │       VD: Please confirm your attendance by May 5.
│   │       → Vui lòng xác nhận tham dự trước ngày 5/5.
│   │
│   ├── 10.4. Instructions / Procedures
│   │   ├── Điều kiện
│   │   ├── First / next / finally
│   │   ├── Before / after + V-ing
│   │   └── Once / when / if + clause
│   │       VD: Before submitting, check all fields.
│   │       → Trước khi nộp, hãy kiểm tra các trường.
│   │
│   ├── 10.5. Report / Review / Proposal
│   │   ├── Report: dữ liệu / kết quả
│   │   ├── Review: đánh giá
│   │   ├── Proposal: đề xuất
│   │   └── Recommendation: khuyến nghị
│   │       VD: We recommend improving the process.
│   │       → Chúng tôi khuyến nghị cải thiện quy trình.
│   │
│   ├── 10.6. Purpose & Audience
│   │   ├── Ai viết?
│   │   ├── Viết cho ai?
│   │   ├── Mục đích chính?
│   │   └── Người đọc cần làm gì?
│   │       VD: HR emails employees about training.
│   │       → HR gửi email cho nhân viên về đào tạo.
│   │
│   └── 10.7. Bẫy văn bản
│       ├── Ngày bắt đầu vs. hạn chót
│       ├── Người được nhắc đến vs. người nhận
│       ├── Chi tiết phụ vs. mục đích chính
│       └── Từ khóa trùng nhưng sai ý
│           VD: "by May 5" = hạn chót, không nhất thiết là ngày sự kiện.
