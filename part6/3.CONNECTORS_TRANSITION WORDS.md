3.2 — Cause & Effect

① because
   = bởi vì
   → Clause (S + V)

② because of
   = bởi vì
   → N / Noun Phrase / V-ing

③ therefore
   = vì vậy / do đó
   → Therefore, + S + V

④ as a result
   = kết quả là / do đó
   → As a result, + S + V

⑤ consequently
   = do đó / vì vậy
   → Consequently, + S + V
