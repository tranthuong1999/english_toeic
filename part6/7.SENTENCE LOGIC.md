7. SENTENCE LOGIC

7.1  Sentence Logic là gì?
     - Logic của câu là gì?
     - Khác Vocabulary / Collocation như thế nào?
     - Khi nào cần dựa vào logic?

7.2  Cause → Effect
     - Nguyên nhân → Kết quả
     - because / therefore / as a result
     - Nhận diện quan hệ nguyên nhân – kết quả

7.3  Problem → Solution
     - Vấn đề → Giải pháp
     - complaint → resolve
     - problem → solution
     - delay → corrective action

7.4  Action → Purpose
     - Hành động → Mục đích
     - to + V
     - in order to + V
     - so that + S + V

7.5  Statement → Explanation
     - Thông tin → Giải thích
     - in other words
     - that is
     - explanation trong context

7.6  Contrast / Unexpected Result
     - Ý A → nhưng / trái ngược → Ý B
     - however
     - although
     - despite
     - nevertheless

7.7  Sequence / Time Logic
     - Trình tự trước → sau
     - first
     - then
     - afterward
     - finally
     - before / after

7.8  Logic giữa các câu
     - Câu trước ảnh hưởng câu sau thế nào?
     - Không chỉ nhìn blank
     - Đọc 2–3 câu để xác định logic

7.9  Logic trong toàn đoạn
     - Chủ đề chính
     - Vấn đề
     - Hành động
     - Kết quả
     - Mục đích
     - Kết luận

7.10 Bẫy Sentence Logic
      - Đúng grammar nhưng sai logic
      - Đúng nghĩa riêng lẻ nhưng sai context
      - Nhầm Cause với Effect
      - Nhầm Problem với Solution
      - Nhầm Action với Purpose
      - Chọn đáp án vì từ khóa giống nhau

* The company received many complaints about its slow customer service. As a result, it decided to ______ more employees to the support team.

A. hire
B. reduce
C. cancel
D. postpone

| Đáp án      | Nghĩa    | Logic                                      | Kết quả |
| ----------- | -------- | ------------------------------------------ | ------- |
| **A. hire** | tuyển    | giải quyết tình trạng thiếu nhân viên      | ✅       |
| B. reduce   | giảm     | giảm nhân viên có thể làm dịch vụ chậm hơn | ❌       |
| C. cancel   | hủy      | không liên quan                            | ❌       |
| D. postpone | trì hoãn | không phù hợp                              | ❌       |

7.5 — Statement → Explanation
Dạng này là:
Statement (Thông tin/ý được đưa ra) → Explanation (Giải thích)
Tức là:

Nói một thông tin → giải thích rõ hơn thông tin đó

| Cụm                | Ý nghĩa       |
| ------------------ | ------------- |
| **in other words** | nói cách khác |
| **that is**        | tức là        |
| **namely**         | cụ thể là     |
| **specifically**   | cụ thể là     |
The company has introduced a flexible work policy. ______, employees can choose to work from home two days a week.

A. As a result
B. In other words (
C. However
D. For example
