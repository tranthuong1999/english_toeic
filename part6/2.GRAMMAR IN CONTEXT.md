2.2 — Verb Tense trong Context

Ở Part 5, bạn đã học các thì. Sang Part 6, điểm khác biệt là:

Không chỉ nhìn một câu → phải dùng thông tin trong context để xác định thời điểm của hành động.

Ví dụ

The company launched its new website last month. Since then, customer traffic has increased significantly.

Ta có:

last month → thời điểm quá khứ cụ thể → Past Simple
Since then → bắt đầu từ quá khứ và kéo dài đến hiện tại → Present Perfect

| Dấu hiệu                        | Thường dùng                      |
| ------------------------------- | -------------------------------- |
| yesterday / last year / in 2024 | **Past Simple**                  |
| now / currently / at present    | **Present / Present Continuous** |
| since + mốc thời gian           | **Present Perfect**              |
| for + khoảng thời gian          | **Present Perfect**              |
| already / yet / recently        | thường **Present Perfect**       |
| every year / usually / often    | **Present Simple**               |
| by the time + quá khứ           | thường cần xét **Past Perfect**  |

2.9 — Comparison trong Context
Adj-er + than
This model is cheaper than the previous one.
Với tính từ dài:
more + Adj + than
This system is more efficient than the old one.

the + Adj-est
This is the most efficient option.
as + Adj + as
The new system is as reliable as the old one.

* The new software is ______ efficient than the previous version, allowing employees to complete their tasks more quickly.

A. most
B. more (
C. much
D. very

| Đáp án  | Nghĩa     | Cấu trúc / Sau nó là gì? | Kết quả |
| ------- | --------- | ------------------------ | ------- |
| A. most | nhất      | `the most + Adj`         | ❌       |
| B. more | hơn       | `more + Adj + than`      | ✅       |
| C. much | nhiều/rất | `much + comparative`     | ❌       |
| D. very | rất       | `very + Adj`             | ❌       |

Recap:
| Loại         | Công thức           | Ví dụ               |
| ------------ | ------------------- | ------------------- |
| So sánh hơn  | `Adj-er + than`     | faster than         |
| So sánh hơn  | `more + Adj + than` | more efficient than |
| So sánh nhất | `the + Adj-est`     | the fastest         |
| So sánh nhất | `the most + Adj`    | the most efficient  |
| Bằng nhau    | `as + Adj + as`     | as efficient as     |
