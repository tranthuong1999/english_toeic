├── 1. WORD FORMS — TỪ LOẠI
│   │
│   ├── 1.1. Danh từ (Noun)
│   │   └── We need more information.
│   │
│   ├── 1.2. Động từ (Verb)
│   │   └── She manages the department.
│   │
│   ├── 1.3. Tính từ (Adjective)
│   │   └── The report is accurate.
│   │
│   ├── 1.4. Trạng từ (Adverb)
│   │   └── She responded quickly.
│   │
│   ├── 1.5. Hậu tố nhận biết từ loại
│   │   ├── N: -tion, -ment, -ness → development
│   │   ├── Adj: -ive, -al, -ous → effective
│   │   ├── Adv: -ly → carefully
│   │   └── V: -ize, -ify → organize, simplify
│   │
│   └── 1.6. Phân biệt từ cùng gốc
│       └── The company improved its ______.
│           → performance (danh từ)

│   ├── 2.1. Chủ ngữ số ít
│   │   └── The manager works every day.
│   │
│   ├── 2.2. Chủ ngữ số nhiều
│   │   └── The employees work every day.
│   │

│   │
│   ├── 2.4. Each / Every / Everyone
│   │   └── Each employee has an ID card.
│   │
│   └── 2.5. Either...or / Neither...nor
│       └── Either the manager or the employees are attending.

├── 3. PREPOSITIONS — GIỚI TỪ
│   │
│   ├── 3.1. Giới từ thời gian
│   │   ├── in + tháng/năm → in July, in 2026
│   │   ├── on + ngày → on Monday
│   │   └── at + giờ → at 9 a.m.
│   │
│   ├── 3.2. Giới từ địa điểm
│   │   ├── in + bên trong/khu vực → in the office
│   │   ├── on + bề mặt → on the desk
│   │   └── at + địa điểm cụ thể → at the entrance
│   │
│   ├── 3.3. Giới từ theo sau tính từ/động từ
│   │   └── responsible for the project
│   │
│   ├── 3.4. Giới từ + N/V-ing
│   │   └── interested in learning English
│   │
│   └── 3.5. Cụm dễ nhầm: to là giới từ
│       └── look forward to meeting you

├── 5. GERUND & INFINITIVE — V-ING / TO V
│   │
│   ├── 5.1. Verb + V-ing
│   │   └── We avoid making unnecessary changes.
│   │
│   ├── 5.2. Verb + to V
│   │   └── We plan to expand the business.
│   │
│   ├── 5.3. Verb + O + to V
│   │   └── The manager asked us to attend.
│   │
│   ├── 5.4. Giới từ + V-ing
│   │   └── Thank you for helping us.
│   │
│   └── 5.5. Cấu trúc đặc biệt
│       ├── allow + O + to V → They allow staff to work remotely.
│       ├── make + O + V → The news made us reconsider.
│       └── need + to V → We need to update the file.

├── 7. CONJUNCTIONS — LIÊN TỪ & TỪ NỐI
│   │
│   ├── 7.1. Nguyên nhân
│   │   ├── because + mệnh đề
│   │   │   └── We left because it was late.
│   │   └── because of + N/V-ing
│   │       └── We left because of the delay.
│   │
│   ├── 7.2. Kết quả
│   │   └── It rained, so the event was canceled.
│   │
│   ├── 7.3. Tương phản
│   │   ├── although + mệnh đề
│   │   │   └── Although it rained, we continued.
│   │   └── despite + N/V-ing
│   │       └── Despite the rain, we continued.
│   │
│   ├── 7.4. Bổ sung
│   │   └── Both the manager and the assistant attended.
│   │
│   ├── 7.5. Lựa chọn / phủ định kép
│   │   ├── either...or → Either Monday or Tuesday works.
│   │   └── neither...nor → Neither option is available.
│   │
│   └── 7.6. Phân biệt liên từ và giới từ
│       └── Despite the delay, we finished on time.

├── 8. RELATIVE CLAUSES — MỆNH ĐỀ QUAN HỆ
│   │
│   ├── 8.1. Who — người, làm chủ ngữ
│   │   └── The employee who called you is here.
│   │
│   ├── 8.2. Whom — người, làm tân ngữ
│   │   └── The client whom we contacted replied.
│   │
│   ├── 8.3. Which — vật/sự việc
│   │   └── The report which arrived today is important.
│   │
│   ├── 8.4. That — người/vật trong mệnh đề xác định
│   │   └── The file that I sent is attached.
│   │
│   ├── 8.5. Whose — sở hữu
│   │   └── The employee whose laptop broke called IT.
│   │
│   ├── 8.6. Where — nơi chốn
│   │   └── This is the office where she works.
│   │
│   └── 8.7. Xác định chỗ trống thiếu gì
│       └── The person ______ manages the team is helpful.
│           → who (thiếu chủ ngữ)
