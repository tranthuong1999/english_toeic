Superlative — So sánh nhất

1. Định nghĩa
So sánh nhất dùng khi muốn nói một người/vật có mức độ cao nhất hoặc thấp nhất trong một nhóm.
S + be + the + Adj-est + ...
This is the fastest computer in the office.
S + be + the most + Adj + ...
This is the most expensive computer in the office.

| So sánh hơn             | So sánh nhất           |
| ----------------------- | ---------------------- |
| `Adj-er + than`         | `the + Adj-est`        |
| `more + Adj + than`     | `the most + Adj`       |
| faster **than**         | **the** fastest        |
| more expensive **than** | **the most** expensive |

So sánh hơn thường cho 2 đối tượng 
This computer is faster than that one.
So sánh 1 đối tượng với cả nhóm.
This is the fastest computer in the office.
